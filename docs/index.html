Principles

Small footprint. No telemetry. No rubber stamps.

  1. 01Lightweight

    Loaded when you open it. Gone when you close it.

    Tools and editors load on demand and free their memory when they close. No desktop widgets. Audio, network and clipboard readings run only while their surface is open.

    < 450 MBshell + Niri, measured with the profiler in the repo

  2. 02No telemetry

    Nothing phones home.

    No analytics, no accounts, no crash reports. Three features touch the network, and only to fetch what they show: weather from Open-Meteo, lyrics from LRCLIB and wallpaper search on Wikimedia Commons.

    0trackers in the shell or on this site

  3. 03Sleek

    Strange to look at. Predictable to use.

    Orbits, imperfect silhouettes and surfaces that unfold instead of snapping open. Controls stay legible and stay put. A button never moves out from under your pointer.

    Offis a motion setting too

  4. 04Not LGTM’d

    Reviewed, not rubber-stamped.

    Python, QML, Node and Rust test suites gate every change, and every known limit is written down. Nothing merges on a glance.

    4test suites, one tools/check

Install

Five commands, then you’re in orbit.

Tonantzintla 1.1 runs on Niri with Quickshell, on Arch Linux, Arch-based distributions and Obarun.

Installation guide Dependencies Releases
  • Your Niri configuration stays as it is.
  • On Obarun, enable obcommunity first.
  • Artix is unsupported, on purpose.
bash
sudo pacman -S --needed git rust
git clone https://github.com/deltadasher/Tonantzintla.git
cd Tonantzintla
./bin/blackhole install --profile recommended --niri keep --umbra lock
~/.local/bin/blackhole start

blackhole doctor checks your setup without touching it.

Questions

Before you install.

Something else? Open an issue
Is this a whole Linux distribution?+

No. It’s a desktop shell for your Wayland session: a bar, desktop tools, wallpaper and music interfaces, and the Umbra lock screen. Your apps and your OS stay yours.

Which systems does it support?+

Niri, on Arch Linux, Arch-based distributions and Obarun. Artix is unsupported, on purpose. Optional features have their own backends, listed in the dependency guide.

Will it replace my Niri configuration?+

No. The commands above use --niri keep, which leaves your configuration alone. Use --niri replace if you want the bundled one instead.

How do I try the lock screen safely?+

Run blackhole preview-lock. It shows Umbra without locking the compositor or touching PAM, and Escape closes it. The preview doesn’t test your password, so read the Umbra first-lock guide before your first real lock.

Something isn’t working. Where do I start?+

Run blackhole doctor to inspect your setup, or blackhole daemon logs for recent shell logs. Still stuck? Open an issue.
