TERMINAL / NIRI SETUP
sudo pacman -S --needed git rust
git clone https://github.com/deltadasher/Tonantzintla.git
cd Tonantzintla
./bin/blackhole install --profile recommended --niri keep --umbra lock
~/.local/bin/blackhole start

Keeps your existing Niri configuration. On Obarun, enable obcommunity first. Read the guide before running.

Something else? Open an issue ↗
Is this a whole Linux distribution?+

It’s a desktop shell built with Quickshell for your Wayland session. It brings together a bar, desktop tools, wallpaper and music interfaces, and the Umbra lock screen. Your applications and operating system stay yours.

Which systems does it support?+

Niri is the supported compositor. The project is tested on Arch Linux, similar derivatives, and Obarun. Artix is intentionally unsupported. Optional features need their own backends; check the dependency guide for your setup.

Will it replace my Niri configuration?+

The commands above use --niri keep to preserve your existing Niri configuration. Choose --niri replace only if you want the bundled configuration. Read the installer’s choices before confirming them.

How do I try the lock screen safely?+

Start with blackhole preview-lock. This previews Umbra without locking the compositor or invoking PAM; Escape closes it. A visual preview doesn’t test authentication. Read the Umbra first-lock and recovery guidance before your first real lock.

Where do I start if something isn’t working?+

Run blackhole doctor to inspect your setup without changing it, or blackhole daemon logs for recent shell logs. Check the dependencies and existing issues before opening a report.
