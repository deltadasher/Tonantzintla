Principles

Light, quiet, and properly checked.

  1. 01Lightweight

    Loaded when you open it. Gone when you close it.

    Tools and editors load on demand and release their models when closed. There are no desktop widgets, and detailed readings for audio, network and the clipboard only run while their surface is open.

    ≤ 450 MBshell + Niri memory budget, checked with a profiler in the repo

  2. 02No telemetry

    Nothing phones home.

    No analytics, no accounts, no crash reporting. The network is only used by features that need it: weather from Open-Meteo, lyrics from LRCLIB and wallpaper search on Wikimedia Commons.

    0trackers in the shell or on this site

  3. 03Sleek

    Strange to look at. Predictable to use.

    Orbits, imperfect silhouettes and surfaces that unfold instead of snapping open. Underneath, controls stay legible and stay put: a button never moves out from under your pointer.

    Offis a valid motion setting

  4. 04Not LGTM’d

    Reviewed, not rubber-stamped.

    Changes run through Python, QML, Node and Rust test suites, and the docs say plainly what hasn’t been tested. A passing check is never treated as proof that something works on your machine.

    4test suites behind one tools/check

Install

Five commands, then you’re in orbit.

Tonantzintla 1.1 runs on Niri with Quickshell. It is tested on Arch Linux, Arch-based distributions and Obarun.

Read the installation guide Dependencies Releases
  • Keeps your existing Niri configuration.
  • On Obarun, enable obcommunity first.
  • Artix is intentionally unsupported.
bash
sudo pacman -S --needed git rust
git clone https://github.com/deltadasher/Tonantzintla.git
cd Tonantzintla
./bin/blackhole install --profile recommended --niri keep --umbra lock
~/.local/bin/blackhole start

Read the guide before running. blackhole doctor checks your setup without changing it.

Questions

Before you install.

Something else? Open an issue
Is this a whole Linux distribution?+

It’s a desktop shell built with Quickshell for your Wayland session. It brings together a bar, desktop tools, wallpaper and music interfaces, and the Umbra lock screen. Your applications and operating system stay yours.

Which systems does it support?+

Niri is the supported compositor. The project is tested on Arch Linux, similar derivatives, and Obarun. Artix is intentionally unsupported. Optional features need their own backends; check the dependency guide for your setup.

Will it replace my Niri configuration?+

The commands above use --niri keep to preserve your existing Niri configuration. Choose --niri replace only if you want the bundled configuration. Read the installer’s choices before confirming them.

How do I try the lock screen safely?+

Start with blackhole preview-lock. This previews Umbra without locking the compositor or invoking PAM; Escape closes it. A visual preview doesn’t test authentication. Read the Umbra first-lock and recovery guidance before your first real lock.

Where do I start if something isn’t working?+

Run blackhole doctor to inspect your setup without changing it, or blackhole daemon logs for recent shell logs. Check the dependencies and existing issues before opening a report.
