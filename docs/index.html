Install

Install Tonantzintla.

Tonantzintla 1.1 runs on Niri and Quickshell on Arch Linux, Arch-based distributions and Obarun.

Installation guide Dependencies Releases
  • The commands below keep your Niri configuration.
  • On Obarun, enable obcommunity first.
  • Artix is unsupported.
bash
sudo pacman -S --needed git rust
git clone https://github.com/deltadasher/Tonantzintla.git
cd Tonantzintla
./bin/blackhole install --profile recommended --niri keep --umbra lock
~/.local/bin/blackhole start

blackhole doctor checks your setup.

Questions

Installation and support.

Open an issue
Is this a whole Linux distribution?+

No. It is a desktop shell for a Wayland session.

Which systems does it support?+

Niri on Arch Linux, Arch-based distributions and Obarun. Artix is unsupported. Optional backends are listed in the dependency guide.

Will it replace my Niri configuration?+

The commands above use --niri keep. Use --niri replace to replace your configuration.

How do I try the lock screen safely?+

Run blackhole preview-lock to preview Umbra without locking or testing PAM. Press Escape to exit. Read the Umbra first-lock guide before your first real lock.

Something isn’t working. Where do I start?+

Run blackhole doctor or blackhole daemon logs. Open an issue.
