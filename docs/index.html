Operating principle

Strange shapes. Dependable actions.

Tonantzintla keeps the desktop legible while letting its surfaces move, breathe, and occasionally misbehave beautifully.

MotionSurfaces unfold, instruments settle, and changes have a visible path instead of teleporting.
MaterialSolid dark backs, translucent controls, rounded clipping, and a palette that follows the sky.
PortableShared source stays clean while monitor layout, devices, wallpapers, and preferences stay local.
HonestOptional integrations report what is available, what is pending, and what actually failed.
Bring it home

Start at the event horizon.

Clone the project, let the doctor inspect your machine, and bring up the shell from a terminal before wiring it into Niri.

$ git clone https://github.com/deltadasher/Tonantzintla.git
$ cd Tonantzintla
$ ./bin/blackhole doctor
$ ./bin/blackhole install
$ ~/.local/bin/blackhole run
# the desktop is yours to arrange
