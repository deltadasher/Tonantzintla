What Ephemeris does

Give each task enough room.

Use the bar for quick checks and Ephemeris for the controls that need a little more space.

Command palette

Search by name first, then launch apps, shell actions, and settings from one place.

Settings

Change appearance, motion, bar layouts, monitors, cursors, and Umbra behavior.

Everyday tools

Open calendar, weather, clipboard, notifications, battery, network, audio, and capture.

Monitor aware

Open the tool on the display where you clicked, even when two monitors are connected.

Start here

Open a tool from the bar.

Click an Aperture island, or call Ephemeris directly when a keyboard shortcut is faster.
