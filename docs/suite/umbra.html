Umbra

ApertureEphemerisParallaxResonanceUmbra

A customizable lock surface with a separate preview and an isolated Wayland session-lock path.

Lock preview, not a live lock
PreviewInspect the surface without locking your session. Window shopping, basically.
LockThe separate lock process uses Wayland session lock and PAM.
Checkblackhole lock-status reports whether the lock is really held. No lying.

The rundown

Read the source

The preview command shows the lock surface without acquiring a session lock or authenticating.

The lock command runs a separate Quickshell instance for session locking and PAM authentication.

Try password entry, every display, idle locking and suspend on your own machine first.

Match your login screen to the lock on supported display managers. Matching fits. Setup is in the Umbra guide.

Get started

Start with the preview. When you’re ready, blackhole lock starts the real lock. Check your password and every display before you turn on automatic locking. Locking yourself out is not the vibe.
