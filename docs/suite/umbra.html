What Umbra does

Give the session a clear boundary.

Umbra stays separate from the everyday bar so locking the session does not depend on the rest of the shell.

Safe preview

Check the animation, layout, and monitor coverage before you make it part of your lock flow.

Session lock

Use the installed lock command and let the session manager handle authentication.

Multi-output

Cover every connected display with one consistent lock surface.

Greeter support

Keep the optional greeter adapters available for supported display managers.
