# Theme identities implementation plan

**Goal:** Ship the approved fourteen colored SVG identities in Tonantzintla, selected manually or from the exact theme color, with matching native lock and SDDM illustrations.
**Spec:** User-approved V3 archive, unchanged original snowflake and Wabi Sabi. This plan records that approved direction.
**Architecture:** Pure identity registry and portable QtQuick scene; Settings stores selection; Theme resolves exact color and automatic contrast; ThemeMark renders immutable SVGs. Existing authentication remains responsible for locking and login.
**Stack:** QtQuick/QML, JavaScript, Python, Bash. No web runtime or new dependencies.

## Global Constraints
- Preserve all approved SVG bytes and their literal colors. Keep Wabi Sabi as the default and orange identity; never recolor its black horizon.
- No desktop widgets, telemetry, background services, per-frame Canvas painting, or animation while inactive/reduced-motion.
- Dark identity marks use light backgrounds by default; explicit light/dark choice wins.
- Automatic identity uses the exact chosen color ahead of generated palette colors. Manual identity never changes the palette without a separate explicit action.
- Preserve source versus managed-runtime differences, existing user settings, authentication, lock ownership, PAM, and password lifecycle. Never trigger a real session lock or restart a display manager during testing.
- User requested implementation. Continue without asking to approve this already approved direction.

### Task 1: Identity integration (controller)
Create assets/theme-marks with fourteen SVGs, immutable registry, ThemeMark, settings and Theme Studio identity controls. Use original icon as default, explicit Auto option, and a separate Use this color action. Integrate all theme mark consumers. Implement automatic contrast and palette refresh consistently. Tests cover every exact registered color, neutrals, invalid values, manual override, explicit mode, and original asset hashes.

### Task 2: Portable illustrated scenes (delegated)
Create only src/quickshell/components/identity/ThemeScene.qml and SceneDrawing.js (if useful), plus tests/preview scene fixtures if needed. This pure QtQuick component must work in Quickshell and SDDM without imports of application singletons. Public properties: identity (string), accent (color), lightMode (bool), active (bool), motion (bool), iconSource (url). Readonly scene colors: backgroundColor, foregroundColor, mutedColor, accentColor (contrast-safe for text). Width/height are supplied by caller. Default background selected from lightMode. Draw a polished procedural illustration for each approved identity (ruby, seashell, fire, wabi-sabi, sun, leaf, ice-cube, water-droplet, ringed-planet, night-sky, snowflake, moon, cloud, ink). Wabi can be a quiet original black-hole homage with original icon intact; caller preserves current Wabi lock renderer. Compose around a clear left authentication area (~42% of landscape width); art lives right, with suitable upper-right or lower-right crop in portrait. Include the approved SVG as a meaningful part of each scene. Do not edit SVGs. Subjects: ruby/crystalline geology, seashell/tidal shore, fire/hearth and embers, sun/solar landscape, leaf/branch garden, ice-cube/ice formations, water-droplet/ripples, ringed-planet/orbital paths, night-sky/constellation field, snowflake/winter branches, moon/lunar landscape, cloud/rolling weather, ink/flowing ink. Distinct coherent silhouettes and limited palettes, not a repeating circle behind each logo. Illustrations are generated vectors, not raster images. Use existing Adwaita/shell typography only if needed; no decorative text in scene. Colors: actual approved accent (ruby #D11E40, shell #EE927F, fire #C44F28, wabi #E9B872, sun #EAC64B, leaf #467B50, ice #83DAD9, water #438FCA, planet #9874CD, night #493961, snow #FFFFFF, moon #C8CDD3, cloud #515861, ink #000000). Light defaults: ruby/fire/leaf/night/cloud/ink. Others dark. Canvas may paint only on geometry/theme changes; animations must move cached items with restrained transforms/opacity, active && visible && motion, no polling. Render representative light and dark scenes with native QtQuick and inspect. Root will integrate caller bindings and generate full contact sheet. No nested agents. No commits outside your exact owned files. Report exact files, tests, render artifacts and concerns to the report path given by controller.

### Task 3: Lock and greeter integration (controller)
Load shared ThemeScene for non-Wabi identities in both Umbra variants; leave Wabi renderer and authentication unchanged. Keep clock/status/password readable, preserve layout customization. Stage portable scene + SVG assets into SDDM theme and export resolved identity/mode in theme.conf. Keep supported portable greeter paths working. Do not activate/restart the login manager during development.

### Task 4: Verify, review and install (controller + reviewer)
Run meaningful identity tests, existing tests, native render scenes and controls. Inspect landscape/portrait and light/dark. Review full diff before deploying. Apply only reviewed changes to canonical and managed source, keep recovery snapshots, stage/update through Shellswitch and verify actual running entry/logs/surfaces. Prepare greeter artifact; report installed versus tested state accurately. No real lock/auth test.
