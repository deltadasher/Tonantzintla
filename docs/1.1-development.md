# 1.1 development

This is a development pass, not a released 1.1 or a claim of live desktop
acceptance. Installed state must be checked separately from this source tree.
The current implementation order and acceptance criteria are in
[the Gemini roadmap](gemini-roadmap-1.1.md).

## Implemented

- **One transition owner:** a requested tab is separate from displayed content.
  Exit, asynchronous loading, entrance and cancellation have explicit phases.
  Reduced motion uses short fades, not spatial movement. A failed widget gets a
  retry state instead of preventing the whole shell from loading.
- **Blackhole palette:** applications, instruments, settings and known media/
  session actions in one search. `>` filters commands. Arrows and Enter select;
  Escape closes; Ctrl+P saves an application. Name matches rank ahead of metadata;
  empty searches and equal-strength matches keep stable ordering. Launch frequency
  influences typography, not search position.
- **Parallax orbit:** the established orbiting presentation remains the default;
  the newer library/grid experiment is withdrawn from the surface for now. The
  local library backend remains isolated for a future reintroduction after a
  dedicated visual pass.
- **Solar timeline:** weather-location day/night, provider sunrise/sunset and
  explicitly approximate civil dawn/dusk and solar noon. DST day lengths and
  polar conditions are represented. A changed location cannot accept a late
  response from the previous one.
- **Audio routes:** native PipeWire connections, with playback rerouting by drag
  or select-stream/select-output (keyboard supported). Existing volume controls
  remain available. The compatibility helper resolves fresh object serials to
  PulseAudio indices; it does not change default routing policy. Cables have
  fixed width: they do not pretend volume settings are measured signal peaks.
- **Actual bar preview:** settings reuses Aperture's real components and data,
  scaled to the focused output, with input disabled and no second bar window.
- **Event horizon:** temporary deep focus dims the bar, stills the atmosphere
  and withholds new noncritical popups, while keeping notification history.
  Existing Do Not Disturb remains authoritative.
- **Local widget contract:** one catalog feeds the host and command palette;
  optional focus/deployment hooks are documented in architecture.md.

## Validation

`./tools/check` selects Qt 6 tools on Arch, runs helper and installer tests,
compiles actual widget components in Quickshell without constructing services,
and runs offscreen transition-state tests. Compilation is not rendering or
hardware validation. A missing test dependency is explicitly reported as skipped.

Before installing, retain the known-working runtime. On an isolated preview or
after a deliberate local install, verify:

1. Rapidly alternate apps, media, calendar and walls; close mid-transition and
   reopen. Repeat with motion disabled and on different output sizes.
2. Search an app and a `>` action. Exercise arrows, Enter, Escape and saved apps;
   reopen the shell to verify saved-app persistence.
3. Import a local image and video twice. Check originals, unique copies,
   favorite persistence, failed imports and per-output application.
4. Change weather location while loading; check the displayed timezone, today's
   solar marker and no fabricated sunrise during polar conditions.
5. Play two apps. Move only one to headphones, listen, unplug the headphones,
   and verify stale selections cannot move an unrelated stream. Test keyboard
   selection as well as dragging.
6. Change bar settings and compare preview to the real bar. Toggle event horizon,
   verify notification history and critical alerts, then return to normal.

## Still outside this pass

Screenshot-baseline visual regression coverage and live multi-output/audio
acceptance are still required. A redesigned Parallax library surface, animated settings-choice thumbnails, broader
automatic density tuning, a third-party extension installer and speculative
extras from brainstorming are not implemented here. Do not advertise them as
complete. Keep the current version until the 1.1 acceptance gate is met.
