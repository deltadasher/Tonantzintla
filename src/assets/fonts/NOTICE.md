## Exact source and regeneration

Input: `IosevkaNerdFont-Regular.ttf`, Nerd Fonts 3.5.1, Iosevka 34.8.0;
installed package used for verification `ttf-iosevka-nerd 3.5.1-2`.
Input SHA-256: `5e3f3b0a70fcdc5f1ace66ecad69b9913dfd8822fee221dc5e552c7dbc8c17df`.
Output SHA-256: `d45688f2b7bbcc497ec31159c2c4690d9fea3df798a53338da834c2d4f1ae511`.
Output size: 534,512 bytes, 187 encoded codepoints.

From the repository root:

```
python3 tools/build-icon-font.py --source /path/to/IosevkaNerdFont-Regular.ttf
python3 tools/build-icon-font.py --source /path/to/IosevkaNerdFont-Regular.ttf --check
```

The offline build helper uses Python stdlib ctypes and public system HarfBuzz
subset/builder APIs. It rejects a different input hash. It retains glyph IDs,
outline bytes (apart from trailing padding), advances/bearings and TrueType hint
programs, checking them against the original. Runtime needs only Qt FontLoader;
there is no runtime font generation, helper process, network access or global
fontconfig change. `glyphs.json` is the reviewed repertoire. Additions require a
source/license audit and native pixel comparison before regeneration.

## Runtime fallback and limits

`Theme.fontIcon` continues to mean the user's configured family.
`Theme.iconFamily(text)` returns the bundled family only for the exact default
setting `Iosevka Nerd Font`, when the local FontLoader is Ready and every Unicode
scalar in the string is covered. Otherwise it returns the configured family
unchanged. Unknown characters cannot silently become missing glyphs merely
because a subset was introduced; the original configured font remains responsible
for them.

Superscripts U+00B2/U+00B3/U+00B9/U+2070 and weather lightning U+03DF deliberately
use the original family: native rendering through the renamed family differed
on this host despite equal nominal outlines. Any fallback can load the larger
original font and reduce or erase the memory saving. Missing original system
fonts retain the user's existing system fallback behavior. This optimization is
not a universal 450 MB shell/compositor guarantee.
